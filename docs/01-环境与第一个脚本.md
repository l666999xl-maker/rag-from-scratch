## 先理解三件事

### 1. 为什么用 `python -m src.xxx`，而不是 `python src/xxx.py`

`-m` 表示"把 `src` 当成一个包来运行"。
这样文件之间可以互相 import（`from src.config import ...`），
而直接跑文件会找不到 `src` 这个包。

**记住一条：所有命令都在项目根目录执行，用 `-m` 形式。**

### 2. `.env` 是什么

一个纯文本文件，存密钥：

```
DEEPSEEK_API_KEY=sk-xxxx
DASHSCOPE_API_KEY=sk-yyy
```

代码用 `python-dotenv` 读它。**密钥不写进代码**，否则一提交到网上就泄露了。

### 3. 配置集中在一个文件

`src/config.py` 负责把所有路径和密钥读进来。
其他脚本只从它这里取，不在自己文件里硬编码。

**为什么**：以后换目录、换模型，只改一个地方。

```
DASHSCOPE_API_KEY=...

```

### 第二步：写 `src/config.py`

```python
"""全局配置：路径 + 密钥。"""
import os
from pathlib import Path

from dotenv import load_dotenv

# 项目根目录（src 的上一级）
ROOT = Path(__file__).resolve().parent.parent

load_dotenv(ROOT / ".env")

# 对话模型
DEEPSEEK_API_KEY = os.getenv("DEEPSEEK_API_KEY")
DEEPSEEK_BASE_URL = os.getenv("DEEPSEEK_BASE_URL", "https://api.deepseek.com")
CHAT_MODEL = os.getenv("MODEL", "deepseek-v4-flash")

# 向量模型
DASHSCOPE_API_KEY = os.getenv("DASHSCOPE_API_KEY")
EMBEDDING_BASE_URL = os.getenv("EMBEDDING_BASE_URL")
EMBEDDING_MODEL = os.getenv("EMBEDDING_MODEL")

# 目录
PDF_DIR = ROOT / "data" / "raw" / "pdf"
BUILD_DIR = ROOT / "build"


def check() -> list[str]:
    """检查必需的配置项，返回缺失项列表。"""
    required = {
        "DEEPSEEK_API_KEY": DEEPSEEK_API_KEY,
        "DASHSCOPE_API_KEY": DASHSCOPE_API_KEY,
        "EMBEDDING_BASE_URL": EMBEDDING_BASE_URL,
        "EMBEDDING_MODEL": EMBEDDING_MODEL,
    }
    return [name for name, value in required.items() if not value]
```

**这一段的关键点**：

- `Path(__file__).resolve().parent.parent` = 从 `src/config.py` 往上两级 = 项目根目录
- `load_dotenv(ROOT / ".env")` = 明确指定 .env 的位置，不依赖当前工作目录
- `os.getenv("MODEL", "deepseek-v4-flash")` = 读不到就用默认值

### 第三步：写 `src/step1_check.py`

```python
"""第 1 步：确认环境和密钥都就绪。"""
from src.config import BUILD_DIR, PDF_DIR, check


def main() -> None:
    print("=" * 50)
    print("  环境自检")
    print("=" * 50)

    missing = check()
    if missing:
        print("缺少配置：", "、".join(missing))
        print("请把 project1-rag-agent/.env 复制到本项目根目录，改名为 .env")
        return

    print("密钥配置：OK")
    print("PDF 目录：", PDF_DIR)
    print("PDF 数量：", len(list(PDF_DIR.glob("*.pdf"))))
    print("中间产物目录：", BUILD_DIR)

    BUILD_DIR.mkdir(exist_ok=True)
    print("\n环境就绪，可以开始第 2 步。")


if __name__ == "__main__":
    main()
```

### 第四步：创建 `src/__init__.py`

空文件就行，作用是告诉 Python "src 是一个包"。

## 如果报错

| 报错 | 原因 | 解决 |
|---|---|---|
| `ModuleNotFoundError: No module named 'src'` | 不在项目根目录 | `cd` 到 project7-test-rag |
| `ModuleNotFoundError: No module named 'dotenv'` | 用了错误的环境 | 用 `rag-agent` 环境，或 `pip install python-dotenv` |
| `缺少配置：DEEPSEEK_API_KEY` | `.env` 没放对位置 | 确认 `.env` 在项目根目录（和 `src/` 同级） |
| `SyntaxError` | 复制时带了多余字符 | 检查引号、括号是否成对 |
