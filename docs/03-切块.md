## 先理解三件事

### 1. 为什么必须切块

两个原因：

**一是检索精度。** 一整页 800 字，用户问"起付线是多少"，
你把整页返回给模型，模型要自己从 800 字里找那一句。切小之后，
检索命中的块里大部分都是相关内容。

**二是成本。** 每次问答塞给模型的文字都要按 token 计费。
塞 800 字和塞 200 字，成本差 4 倍。

### 2. 切多大合适

没有标准答案，**必须实测**。

| 切太小 | 切太大 |
|---|---|
| 语义被切碎，一块里没有完整信息 | 噪声多，检索精度下降 |
| 检索命中率高但内容不完整 | 一块里什么都有，模型抓不住重点 |

经验值：中文 300~600 字。本项目用 **500**。

### 3. 要在语义边界切

政策文本有三个天然边界：

```
第X条          ← 最重要，一条就是一件事
一、（一）      ← 分项
。 ；            ← 句子
```

按这些边界切，切出来的块才是"完整的意思"。

## 动手

把 `src/step3_chunk.py` 换成下面这段。

### 第一步：导入和常量

```python
import json
import re

from src.config import BUILD_DIR

CHUNK_SIZE = 500
MIN_CHUNK_SIZE = 40

ARTICLE_RE = re.compile(r"(?<!^)(?=第[一二三四五六七八九十百零]+条)")
```

**解释 `ARTICLE_RE`**：

- `第[一二三四五六七八九十百零]+条` 匹配"第八条""第三十四条"
- `(?=...)` 是**前瞻**：匹配位置但不消耗字符
- `(?<!^)` 是**后顾**：前面不能是行首，避免在开头重复插换行

效果：在"第八条"前面插入一个换行，让它成为独立段落。

### 第二步：切分函数

```python
def split_text(text: str, size: int = CHUNK_SIZE) -> list[str]:
    text = ARTICLE_RE.sub("\n", text)

    paragraphs = [p.strip() for p in text.split("\n") if p.strip()]

    chunks: list[str] = []
    buffer = ""

    for para in paragraphs:
        if len(para) >= size:
            if buffer:
                chunks.append(buffer)
                buffer = ""
            chunks.append(para)
            continue

        if len(buffer) + len(para) <= size:
            buffer = buffer + para
        else:
            chunks.append(buffer)
            buffer = para

    if buffer:
        chunks.append(buffer)

    return [c for c in chunks if len(c) >= MIN_CHUNK_SIZE]
```

**这段的逻辑**：

1. 先在条款前插换行，把长文本拆成"段落"
2. 用一个 `buffer` 累积段落，直到超过 `size` 就吐出去
3. 单个段落本来就超长（比如一整条很长），就让它单独成块
4. 最后丢掉小于 40 字的碎片

**为什么单个超长段落不硬切？**
因为硬切会从句子中间断开。宁可让这一块长一点，也不要切成两半。

### 第三步：主流程

```python
def main() -> None:
    pages = json.loads((BUILD_DIR / "pages.json").read_text(encoding="utf-8"))

    rows = []
    for page in pages:
        parts = split_text(page["text"])
        for i, text in enumerate(parts, 1):
            rows.append({
                "id": f"{page['source']}#{page['page']}#{i}",
                "source": page["source"],
                "page": page["page"],
                "text": text,
            })

    (BUILD_DIR / "chunks.json").write_text(
        json.dumps(rows, ensure_ascii=False, indent=1),
        encoding="utf-8",
    )

    lengths = [len(r["text"]) for r in rows]
    print("=" * 60)
    print(f"块数：{len(rows)}")
    print(f"最短：{min(lengths)} 字　最长：{max(lengths)} 字　平均：{sum(lengths)//len(lengths)} 字")
    print("=" * 60)

    print("\n--- 第 1 块 ---")
    print(rows[0]["text"][:300])
```

**`id` 的格式**：`文件名#页码#块序号`。
后面检索结果要追溯到"哪份文件第几页"，这个 id 就是线索。

## 一个已知问题

你会看到第 1 块是**目录**：

```
目 录医院简介 ………第 1 页门诊楼层分布 ………第 5 页
```

目录里有所有章节标题，但没有实际内容。它会污染检索——
搜什么都能匹配上它。

**这是留给你的练习**：怎么把目录过滤掉？

提示：目录行的特征是「标题 + 一串省略号 + 第 N 页」。
统计一段里这种行占多少，超过一半就整段丢掉。

（参考实现在 project1-rag-agent 的 `src/ingestion/pdf_loader.py` 里的
`looks_like_toc`。但建议先自己写。）
