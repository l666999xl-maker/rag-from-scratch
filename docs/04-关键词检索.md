## 先理解三件事

### 1. BM25 的核心思想

一句话：

> **一个词在这块文本里出现得越多，这块越相关；
> 但如果这个词在所有文本里都很常见，它的区分度就低。**

用两个量描述：

| 量 | 含义 | 例子 |
|---|---|---|
| **TF**（词频） | 这个词在本块出现几次 | "起付线"在块里出现 3 次 |
| **IDF**（逆文档频率） | 这个词在多少块里出现过 | "的"出现在几乎所有块 → 权重极低 |

BM25 把两者加权组合，还做了长度归一化（防止长块因为词多而占便宜）。

### 2. 中文必须先分词

英文天然有空格：

```
"medical insurance" → ["medical", "insurance"]
```

中文没有：

```
"医保报销比例" → 如果不分词，整句是一个"词"
```

如果整句是一个词，那么**每一块里这个词都只出现一次**，
TF 全是 1，区分度为零——BM25 完全失效。

所以要用 jieba 先切：

```
"医保报销比例" → ["医保", "报销", "比例"]
```

### 3. 为什么索引只建一次

BM25 要把所有块都分词、统计词频、算 IDF。
这些工作**只在建索引时做一次**，查询时直接用。

如果每次查询都重建，语料一大会非常慢。
（project1 里就踩过这个坑：每次查询都重建，11 个块时无感，240 个块时明显。）

### 第二步：分词函数

```python
def tokenize(text: str) -> list[str]:
    return [w for w in jieba.lcut(text) if w.strip()]
```

`jieba.lcut` 返回列表，可能包含空格和空串，过滤掉。

### 第三步：索引类

```python
class BM25Index:
    def __init__(self, chunks: list[dict]):
        self.chunks = chunks
        self.bm25 = BM25Okapi([tokenize(c["text"]) for c in chunks])

    def search(self, query: str, k: int = 5) -> list[dict]:
        scores = self.bm25.get_scores(tokenize(query))
        order = sorted(range(len(scores)), key=lambda i: scores[i], reverse=True)

        results = []
        for i in order[:k]:
            if scores[i] <= 0:
                continue
            item = dict(self.chunks[i])
            item["score"] = round(float(scores[i]), 3)
            results.append(item)
        return results
```

**逐段解释**：

- `BM25Okapi([...])` 接收的是"每个文档的分词列表"，不是原始文本
- `get_scores(query_tokens)` 返回一个数组，长度 = 块数，每个值是该块的相关性分数
- `sorted(...)` 按分数从高到低排序，取前 k 个
- `if scores[i] <= 0: continue`：完全没匹配上的块分数是 0，返回它们没有意义

### 第四步：加载和展示

```python
def load_index() -> BM25Index:
    chunks = json.loads((BUILD_DIR / "chunks.json").read_text(encoding="utf-8"))
    return BM25Index(chunks)


def show(query: str, k: int = 5) -> None:
    index = load_index()
    print(f"\n查询：{query}\n")
    for rank, item in enumerate(index.search(query, k), 1):
        preview = " ".join(item["text"].split())[:90]
        print(f"  {rank}. [{item['source']} 第{item['page']}页] 分数 {item['score']}")
        print(f"     {preview}…")
```

### 第五步：入口

```python
def main() -> None:
    if len(sys.argv) > 1:
        show(" ".join(sys.argv[1:]))
        return

    print("关键词检索（BM25）。输入 q 退出。")
    while True:
        try:
            query = input("\n查询 > ").strip()
        except (EOFError, KeyboardInterrupt):
            break
        if not query:
            continue
        if query.lower() in {"q", "quit", "exit"}:
            break
        show(query)
```

## 一个可以观察到的现象

搜"医保报销比例"，第 1 名是**学生医保**那份，
而不是《深圳市医疗保障办法》。

**这不是 bug。** BM25 只看词频——学生医保那份文档里
"医保""报销""比例"出现得更密集。

这也说明了一件事：**关键词检索不懂语义，它只数词**。
下一课的向量检索，就是为了解决这个问题。
