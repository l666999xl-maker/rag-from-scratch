## 先理解三件事

### 1. RAG 的生成就是"拼 prompt"

模型本身不知道你医院的规定。是你把检索到的内容塞进 prompt，
它才能"照着念"。

prompt 的结构通常是三段：

```
[角色和规则]  你只能依据资料回答，不要编
[资料]        [1] 来源：xxx.pdf（第3页）……
[问题]        用户的问题
```

### 2. 模型会编，prompt 拦不住

你在 prompt 里写"不要编造"，模型**大部分时候**会听。
但它仍然可能：

- 编一个不存在的文件名作为出处
- 把资料里的数字记错
- 用自己的常识补充资料里没有的内容

**为什么 prompt 拦不住**：因为它是自然语言，是"建议"，不是"规则"。
模型可以选择忽略。

### 3. 用代码做硬校验

本项目做的是**引用校验**：

1. 要求模型必须写 `【来源：文件名】`
2. 从回答里正则提取所有来源
3. 逐个检查：这个文件名，是不是真的出现在本次检索结果里
4. 如果是编的 → 直接替换成兜底话术

这样"模型有没有编出处"就从人工判断变成了**自动判分**。

## 动手

把 `src/step7_answer.py` 换成下面这段。

### 第一步：导入和提示词

```python
import re
import sys

from openai import OpenAI

from src.config import CHAT_MODEL, DEEPSEEK_API_KEY, DEEPSEEK_BASE_URL
from src.step6_hybrid import search

SYSTEM_PROMPT = """你是医院政策咨询助手。用户问医保、预约、就诊相关的问题。

规则：
1. 只能依据下面提供的【资料】回答，不要用自己的知识补充。
2. 资料里没有的信息，直接说"资料中没有相关信息"，不要猜。
3. 回答里的关键结论，必须用【来源：文件名】标注出处。
   只写文件名，不要写页码，例如【来源：sz-medical-insurance-2023.pdf】。
4. 不要编造资料里没有出现过的文件名。
5. 回答简洁，像医院工作人员说话。
"""

CITE_RE = re.compile(r"【来源[：:]\s*([^】]+)】")

FALLBACK = "抱歉，这个问题我没能找到可靠的资料依据，建议您直接联系医院服务台确认。"
```

**为什么规则 3 要强调"不要写页码"**：
我在实测时发现，模型会把"第 3 页"一起写进括号，
导致校验器把 `xxx.pdf 第3页` 当成一个不存在的文件名。
这不是幻觉，是格式不规范——所以提示词和校验器两边都要处理。

### 第二步：拼资料

```python
def build_context(hits: list[dict]) -> str:
    parts = []
    for i, hit in enumerate(hits, 1):
        parts.append(
            f"[{i}] 来源：{hit['source']}（第{hit['page']}页）\n{hit['text']}"
        )
    return "\n\n".join(parts)
```

页码放在括号里，是为了让模型更容易只抄文件名。

### 第三步：校验引用

```python
def _normalize(name: str) -> str:
    name = name.strip()
    name = re.sub(r"[（(]?\s*第\s*\d+\s*页\s*[)）]?.*$", "", name)
    name = re.sub(r"\.(pdf|md|txt)$", "", name, flags=re.I)
    return name.strip()


def verify_citations(answer: str, hits: list[dict]) -> dict:
    cited = list(dict.fromkeys(CITE_RE.findall(answer)))
    valid_sources = {_normalize(h["source"]) for h in hits}

    invalid = [c for c in cited if _normalize(c) not in valid_sources]

    return {
        "cited": cited,
        "invalid": invalid,
        "has_citation": bool(cited),
        "passed": not invalid,
    }
```

**逐段解释**：

- `dict.fromkeys(...)` 去重但保持顺序
- `_normalize` 做两件事：去掉页码后缀、去掉扩展名。
  这样 `xxx.pdf 第3页`、`xxx`、`xxx.pdf` 都能匹配上
- `invalid` = 引用了但不在本次检索结果里的来源

### 第四步：问答主函数

```python
def ask(query: str, top: int = 3) -> dict:
    hits = search(query, top=top)

    messages = [
        {"role": "system", "content": SYSTEM_PROMPT},
        {
            "role": "user",
            "content": f"【资料】\n{build_context(hits)}\n\n【问题】\n{query}",
        },
    ]

    client = OpenAI(api_key=DEEPSEEK_API_KEY, base_url=DEEPSEEK_BASE_URL)
    resp = client.chat.completions.create(
        model=CHAT_MODEL,
        messages=messages,
        temperature=0,
    )
    answer = resp.choices[0].message.content

    check = verify_citations(answer, hits)

    if not check["passed"]:
        answer = FALLBACK

    return {"query": query, "answer": answer, "hits": hits, "check": check}
```

**`temperature=0`**：让输出尽量稳定。问答不需要"创造力"，
而且评测需要可复现。

### 第五步：入口

```python
def main() -> None:
    if len(sys.argv) < 2:
        print('用法：python -m src.step7_answer "你的问题"')
        return

    query = " ".join(sys.argv[1:])
    result = ask(query)

    print("=" * 64)
    print(f"问：{query}")
    print("=" * 64)
    print(result["answer"])

    check = result["check"]
    print("\n" + "-" * 64)
    print(f"引用来源：{check['cited'] or '（无）'}")
    print(f"无效引用：{check['invalid'] or '无'}")
    print(f"校验结果：{'通过' if check['passed'] else '拦截（已降级）'}")
```

## 如果报错

| 报错 | 原因 |
|---|---|
| `401 Unauthorized` | DEEPSEEK_API_KEY 不对 |
| `model not found` | `MODEL` 没配置，默认值也不对 |
| 回答里没有【来源】 | prompt 没生效，检查是否拼进去了 |
| 校验一直"拦截" | 检查 `_normalize`，或者打印 `check["cited"]` 看模型写了什么 |

## 一个你一定会遇到的坑

模型有时会把页码写进引用括号里：

```
【来源：sz-medical-insurance-2023.pdf 第3页】
```

如果你只按"文件名完全相等"校验，会把它误判成幻觉。

**正确做法**：两边都归一化（去页码、去扩展名）再比。
这个坑我在实测中真的踩到了，第 8 课评测会暴露它。
